AI Email Draft Assistant

Automatic reply drafts in James's voice — always reviewed by a person, never sent on its own

When a new email arrives in James's inbox, this system automatically writes a reply in his voice and leaves it waiting as a Gmail draft. Nothing is ever sent on its own — every draft is there for a person to read, adjust, and send. It replaces the older n8n workflow that only checked for new mail every five minutes; this version reacts the moment an email lands.

What it does

The assistant watches James's inbox and, for genuine incoming email that deserves a reply, drafts a response for him. In short, it:

  • Notices the moment a new email lands in the inbox.
  • Writes a reply in James's writing style using AI.
  • Adds James's full email signature to the bottom.
  • Saves it as a Gmail draft on the original conversation.
  • Tags that conversation with the AI Drafts V2 label.
  • Never sends anything — a person always reviews the draft first.

What you'll see

Everything shows up in the normal Gmail mailbox — there is no separate app to open.

  • Draft replies appear directly in James's mailbox, visible to anyone who works the mailbox through delegated access.
  • Every drafted conversation carries the AI Drafts V2 label. Search label:ai-drafts-v2 in Gmail to find them all in one place.
  • Open a draft, edit anything you like, then send it or discard it — exactly like any other Gmail draft.
  • The reply already includes James's signature, so there's nothing to paste in.

Which emails get a draft

The assistant is deliberately selective — it only drafts for real, reply-worthy mail and quietly skips the rest. An email has to pass every check below before a draft is written:

  • It must be in the Inbox — Promotions, Social, Updates and Forums are skipped.
  • It must be from a real person — no-reply senders, and anything James sent himself, are skipped.
  • The conversation must still be open — if James has already replied, or a draft already exists, it's skipped.

Everything that clears those checks gets a draft and the label.

How it's built

Under the hood this is an event-driven pipeline: instead of polling the inbox on a timer, Google notifies the system the instant a new email arrives, and a small cloud function does the rest. Here is the journey of a single email, end to end:

The pipeline, step by step

  • Gmail watch — Gmail is asked to raise a flag every time James's inbox changes.
  • Google Cloud Pub/Sub — a messaging pipe that delivers that flag to our system instantly.
  • The edge function (draft-james-reply) — the brain. It wakes up on each notification and decides what to do.
  • Gmail history — tells the function exactly which new message(s) arrived, so it only looks at what's new.
  • Style samples — a store of James's past emails, used to show the AI how he writes.
  • OpenAI (gpt-4o) — writes the actual reply in James's voice.
  • Gmail drafts & labels — saves the finished reply as a draft and tags the thread.
  • Daily renewal job — a second small function re-arms the inbox watch every day so the notifications never lapse.

Tech stack

  • Supabase edge functions (Deno / TypeScript) — the cloud code that runs it all.
  • Supabase Postgres — stores the processing state and James's style samples; a daily scheduled job (pg_cron) keeps the watch alive.
  • Gmail API — watching the inbox, reading new mail, creating drafts, applying labels.
  • Google Cloud Pub/Sub — instant delivery of inbox notifications.
  • OpenAI gpt-4o — the language model that writes each reply.
  • Google OAuth — lets the system act securely as James's own Gmail account.

Good to know

  • It never sends. The assistant only ever creates drafts; a human decides what actually goes out.
  • It reacts in near real time. Drafts usually appear within moments of an email arriving, not on a five-minute cycle.
  • The voice is tone-level. The AI matches James's style from sample emails; always give a draft a quick read before sending.
  • One draft per conversation. The system won't pile up duplicate drafts on the same thread, even if an email arrives more than once.
  • The inbox watch renews itself daily, so the assistant keeps working without anyone restarting it.
